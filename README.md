## 強豪選手集中度の意味

このデータベースは大会の全参加者ではなく、ポイント取得圏内の選手だけを収録しているため、表示名は「会場全体の強さ」ではなく **ポイント圏に入った選手層の強さ** を示します。

各選手について、同年度・同カテゴリ内の年間CSPパーセンタイルを計算します。上位層を強く評価するため、パーセンタイルを二乗して大会単位で平均します。複数年表示では直近年度の重みを高くし、母数の少ない店舗・都道府県は比較母集団の平均へ縮約します。

## 年間CSPの扱い

優先順位は以下です。

1. CSVに `年間CSP`、`年間合計CSP`、`annual_csp` のいずれかがある場合、その値を使用
2. 上記がない場合、取得済みシティリーグ結果の `獲得CSP` を、`シリーズ年度 × カテゴリ × プレイヤーID` 単位で合算

2の場合はトレーナーズリーグ等を含む公式年間総CSPではないため、画面上では「シティ結果合算」と表示します。

獲得CSPの取得順は次のとおりです。

1. `獲得CSP` / `獲得ポイント` / `CSP` 列
2. `元テキスト` 内の `100pt` など
3. 2024シリーズ以降は順位から補完

2023シリーズは参加定員16名大会と32名以上大会で配点が異なるため、CSVにも元テキストにもCSPがないレコードは補完せず、集中度分析から除外します。

## 推奨CSV列

```text
開催日
大会名
店名
開催都道府県
大会カテゴリ
順位
獲得CSP
年間CSP（任意）
プレイヤーID
プレイヤー名
デッキ名
大会ID
詳細URL
元テキスト
取得日時
```

既存CSVに `開催都道府県` がない場合は、次の順で判定します。

1. CSVの都道府県列
2. `data/store_prefecture_map.csv` の店名対応表
3. `元テキスト` 内の会場住所

`元テキスト` に選手の居住都道府県しかない場合、それを開催都道府県としては使用しません。

## 導入手順

1. ZIPを展開
2. `data/cityleague_results.csv` を本番CSVに差し替え
3. 必要に応じて `data/store_prefecture_map.csv` を更新
4. `config.js` のパスワードを変更
5. GitHubリポジトリへ全ファイルをアップロード
6. GitHubの **Settings → Pages** で公開元を設定

ローカル確認は、フォルダ内で以下を実行します。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。HTMLを直接ダブルクリックすると、ブラウザの制限でCSVを読み込めない場合があります。

## CSV検査

```bash
python tools/validate_csv.py data/cityleague_results.csv
```

プレイヤーID、開催都道府県、CSPの不足件数を確認できます。

## 公式配点の根拠

2024〜2026シリーズのシティリーグは、順位と参加実数に応じて、1位100、2位75、3〜4位50、5〜8位25、9〜16位15 CSPが付与されます。2023シリーズには参加定員16名大会向けの別テーブルがありました。配点変更時は `app.js` の `extractCsp()` を更新してください。
